# 🚂 Switch Track — Train Dispatcher Game

A web-based interactive train routing and town-building game built with **React** and **HTML5 Canvas**.

---

## 📺 Gameplay Demo
Watch the gameplay demonstration on YouTube:  
👉 **[Watch the Video Demo](https://youtu.be/7JDwxbGMJZE)**

---

## 🎮 Game Mechanics
* **Dynamic Track Switching:** Colorful trains (Red, Blue, Green, Yellow) enter from the left. Click track switches to route trains to matching stations.
* **Collision & Penalty System:** Collisions or wrong station entries cost 1 life (3 lives total).
* **Growing Town Progression:** Successful deliveries unlock custom SVG buildings saved via `localStorage`.

---

## 🛠️ Built With
* **Framework:** React
* **Graphics:** HTML5 Canvas & Custom SVGs
* **Styling:** Tailwind CSS
* **Storage:** Web Storage API (`localStorage`)

---

## 🚀 How to Play
Open `oyun.html` directly in any web browser to play instantly.
